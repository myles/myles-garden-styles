# `@mylesb/myles-garden-styles`

> The shared typographic and colour foundation for [myles.garden](https://myles.garden)

A small, CSS-first [Tailwind CSS v4](https://tailwindcss.com) package that defines the design tokens shared across [myles.garden](https://myles.garden) and its sibling projects: four typefaces and a warm parchment-and-sage colour palette, exposed as `@theme` tokens plus a lightly-tuned `prose` utility.

There is no JavaScript config and no build step — you `@import` the CSS and Tailwind turns the tokens into utilities (`font-serif`, `bg-parchment`, `text-sage-dark`, …).

## Requirements

- **Tailwind CSS v4** (`>=4.0.0`) — this package is CSS-first and will not work with v3.
- The [Fontsource](https://fontsource.org) font packages listed under [Typography](#typography), if you want the bundled typefaces to actually load. They are declared as **optional** peer dependencies: the tokens reference the fonts by family name, so system fallbacks apply until you import them.

## Installation

```sh
npm install @mylesb/myles-garden-styles
```

Then install whichever fonts you plan to use:

```sh
npm install \
  @fontsource-variable/inter \
  @fontsource-variable/bitter \
  @fontsource-variable/jetbrains-mono \
  @fontsource/architects-daughter
```

## Usage

Import Tailwind, the fonts you need, and this package from your main stylesheet:

```css
/* app.css */
@import "tailwindcss";

/* Load the typefaces referenced by the tokens */
@import "@fontsource-variable/inter";
@import "@fontsource-variable/bitter";
@import "@fontsource-variable/jetbrains-mono";
@import "@fontsource/architects-daughter";

/* Design tokens + prose utility */
@import "@mylesb/myles-garden-styles";
```

You can also import individual pieces via the package's [exports](#exports):

```css
@import "@mylesb/myles-garden-styles/theme.css"; /* tokens only */
@import "@mylesb/myles-garden-styles/utilities/prose.css"; /* prose only */
```

Once imported, the tokens are available as ordinary Tailwind utilities:

```html
<article class="bg-parchment font-sans text-inkwell">
  <h1 class="font-serif text-sage-dark">In the garden</h1>
  <p class="font-handwritten text-ash">a note in the margin</p>
  <pre class="font-mono">$ npm run build</pre>
</article>
```

## What's inside

### Typography

Four font-family tokens, each backed by a Fontsource typeface with a full system fallback stack.

| Utility            | Typeface                | Fontsource package                    |
| ------------------ | ----------------------- | ------------------------------------- |
| `font-sans`        | Inter Variable          | `@fontsource-variable/inter`          |
| `font-serif`       | Bitter Variable         | `@fontsource-variable/bitter`         |
| `font-mono`        | JetBrains Mono Variable | `@fontsource-variable/jetbrains-mono` |
| `font-handwritten` | Architects Daughter     | `@fontsource/architects-daughter`     |

`font-handwritten` falls back to the serif stack, so it degrades gracefully if the Architects Daughter font isn't loaded.

### The `prose` utility

A small refinement of the `prose` class (as generated by [`@tailwindcss/typography`](https://github.com/tailwindlabs/tailwindcss-typography)):

- widens prose to `max-w-none`, and
- removes the automatic opening/closing quote marks around blockquotes, styling any `<cite>` as a bold, non-italic line prefixed with an em-dash — see [tailwindcss-typography#66](https://github.com/tailwindlabs/tailwindcss-typography/issues/66#issuecomment-2635113327).

## Development

The stylesheets in `src/` are the source of truth — there's nothing to compile. Formatting is handled by [Prettier](https://prettier.io) with
[`@mylesb/prettier-config`](https://www.npmjs.com/package/@mylesb/prettier-config) and the Tailwind plugin:

```sh
npm run prettier        # check formatting
npm run prettier:write  # fix formatting
```
